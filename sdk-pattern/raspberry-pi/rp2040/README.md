# Raspberry Pi RP2040 SDK pattern

This study examines the software architecture used by the Raspberry Pi RP2040 and the Pico SDK.

## Study outline

1. RP2040 hardware context
2. Pico SDK source structure
3. Platform and board support
4. Startup and runtime initialization
5. Register definitions and hardware libraries
6. High level Pico libraries
7. Application entry point
8. GPIO call flow
9. CMake build composition
10. Architecture observations
